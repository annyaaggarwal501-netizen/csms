# Product photos (products 1–50)

Realistic catalogue photos for the 50 seeded products, made with an AI image tool from `docs/PHOTO_PROMPTS_BULK.md`.
The file name is the product number (`9.jpg` = product 9, Banarasi Silk Saree). JPEG, longest side at most 1200 px.

They are already loaded into the shared Neon database. Use this folder only for a **new/empty database**:
app → Products → 📷 Bulk photos → select all 50 files → Upload.

These are sample pictures. For the real shop, replace them with photos of the actual stock (📷 Photo next to a product).
