# Realistic product photos – prompts for Gemini / ChatGPT (all 50 products)

Every prompt asks for a **real-looking photoshoot photo** (real model, real fabric texture, DSLR look) in the same style:
a softly lit pastel café with flowers and natural daylight, so all products look like one catalogue.
Innerwear, socks, handkerchiefs, petticoat, suit fabric and baby items are **product-only** photos (no model).

## How to use
1. Copy one prompt (the grey box under each product) into **Gemini**, **ChatGPT** or **Microsoft Designer**.
2. Check the picture: right colour, right garment, hands and face look natural, no text in the picture. If not, press
   *regenerate*, or reply *"make it more realistic, like a real photo, natural skin texture"*.
3. Download it and **rename the file to the product number**, e.g. `9.jpg` for product 9 (the list below).
4. In the app: **Products → 📷 Bulk photos** → select all the files at once. Each file goes to its product by its number.
   (Or **📷 Photo** next to one product.) Big files are made smaller automatically.

**About watermarks.** Every prompt ends with *"no text, no logo, no watermark"*, so the picture itself has no fake text or
logos. Some tools still add their **own small mark** in a corner (for example a small sparkle icon on some Gemini images).
If you don't want that mark, generate with a tool that doesn't add a visible one, e.g. ChatGPT. Also, AI images are
**samples**: for the real shop, take photos of the actual stock so customers see exactly what they will get.

**Want a plain background instead?** In any prompt replace
*"standing in a softly lit pastel café with pink and lavender flowers, marble tables and pastel striped walls"*
with *"standing in front of a plain light-grey studio wall"*.
